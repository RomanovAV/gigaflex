Спецификация остаётся контрактом, а GigaLphex ведёт задачи, коммиты, review и finalize.

Шаг 01

Подготовьте окружение

Страница ничего не устанавливает. Чекбоксы — это подсказка, их можно пропустить.

Шаг 02

Выберите source of truth

OpenSpec — основной путь. Superpowers и обычный план остаются дополнительными вариантами.

Шаг 03

Используйте общую конфигурацию

Команда запуска останется короткой: GigaLphex сам прочитает модели и параметры выполнения из config.
Откуда берутся настройкиФлаги в каждой команде не нужны
01 · ~/.config/gigalphex/config — общие настройки 02 · .gigalphex/config — настройки конкретного проекта 03 · проектный config при необходимости переопределяет общий
Для первого запускаДополнительная настройка не обязательна
Команда --init подготовит .gigalphex/config. Если config уже существует, GigaLphex использует его без изменений.
